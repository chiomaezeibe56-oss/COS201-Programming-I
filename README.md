COS 201 - Programming I

Week 3: Variables and Input/Output

Objectives

- Understand variables and data types in Java.
- Use Scanner to accept user input.
- Perform arithmetic operations.
- Display output using Java.

Programs

1. SimpleCalculator.java
Accepts two numbers and calculates their sum, difference, product, and quotient.

2. AverageCalculator.java
Accepts a student's name and three scores, then calculates the total and average score.

3. ItemCost.java
Accepts an item name, quantity, and unit price, then calculates the total cost.

How to Run

1. Open the terminal.
2. Navigate to the week03 folder.
3. Compile a program using:

"javac SimpleCalculator.java"

4. Run it using:

"java SimpleCalculator"

Repeat for the other programs using their respective filenames.
