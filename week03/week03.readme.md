Variables, Data Types, Expressions and Input/Output

Objective

To understand how Java programs store information, perform calculations, receive user input and display results.

Topics Covered

Variables and constants.
Java data types.
Variable declaration and initialization.
Arithmetic expressions.
User input using Scanner.
Displaying output.
Practical Programs

"week03/AverageCalculator.java"

Calculates the total and average of three student scores.
"week03/SimpleCalculator.java"

Performs arithmetic calculations using two numbers.
Learning Outcome

I learned how to use variables, work with different data types, perform arithmetic calculations, receive user input and display results using Java.
